# Credential values in the privacy egress gate (C-032)

Generated by `S3.Gliner2Targets credentials`. Detector rules: `CredentialDetector.Egress` (shapes and labelled values). GLiNER2: gliner2-base-v1 on the CPU, labels person, email, phone number, address, account number, credential, threshold 0.4, with the gate's filters. A value is covered when every non-space character lies inside some span (`PiiEval.Covered`); a span is a false positive when it neither contains nor lies within a labelled value of its text.
